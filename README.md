# Oral Exam Tracker

A lightweight, single-file browser tool for teachers to schedule and monitor oral exam sessions in real time. No installation, no backend, no data leaves your device.

## Features

- Define the list of students or groups (by name)
- Set a custom slot duration per student
- Set the overall session start and end time
- Auto-generate the planned schedule
- Track actual start and end times with one click (or enter them manually)
- See running delay at a glance, per student and for the whole session
- Estimated session end time updates live as you go

## Usage

1. Open `index.html` in any modern browser — no server needed.
2. Fill in the session times and default slot duration.
3. Add your students or groups, adjusting individual durations where needed.
4. Click **Generate schedule**.
5. During the exam, use **Start** and **End** buttons to log actual times. The ✎ icon lets you enter a time manually if you forgot to tap at the right moment.

## Deployment

This is a static single-file app. To host it for free on GitHub Pages:

1. Upload `index.html` to a public GitHub repository.
2. Go to **Settings → Pages**, set source to the `main` branch, root folder.
3. Your page will be live at `https://YOUR_USERNAME.github.io/REPO_NAME/` within a minute.

## Tech

Plain HTML, CSS, and vanilla JavaScript. No frameworks, no dependencies, no build step. The only external resource is the [DM Sans + DM Mono](https://fonts.google.com/) font loaded from Google Fonts.
